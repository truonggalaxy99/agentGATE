Về AgentGate

Cổng ownership-gated: chỉ Agent ID của bạn mới mở dashboard Web3 × AI Agent trên BNB Smart Chain.

Agent ID đã tương tác on-chain —

AgentGate chứng minh bạn sở hữu name.ai bằng checkIn on-chain (Binance AI / prompt riêng tư, hoặc ví chủ). Sau đó mới mở số dư, Swap / Perp / Predict / Earn và công cụ Approve · Bridge · Cancel.

Luồng AI Agent luôn simulate → confirm → execute. AgentGate không tự ký, không lưu seed / private key, không đăng nhập Agentic Wallet bằng QR trên web.

  • Hai lối vào: Web3 Wallet hoặc AI Agent (Agent ID)
  • Trust thiết bị 24 giờ sau khi xác minh; Đăng xuất xoá trust
  • Intent on-chain: checkIn · logIntent · recordAction
  • Không phải công cụ tra ví người khác theo tên

Tầm nhìn

Hiện có → hướng dài hạn. Tầm nhìn kỹ thuật — không cam kết tự trade / kiếm tiền hộ.

Hiện có

  • Identity gate bằng name.ai
  • Intent → simulate → user confirm → ký
  • Audit on-chain (checkIn / logIntent)
  • Dual Web3 × Agent

Tầm nhìn

  • Agent chạy trong permission / hạn mức user đã cấp — ít bước hơn, vẫn có kiểm soát
  • UX một chạm như CEX (vẫn confirm khi đụng tài sản)
  • Agent hiểu rủi ro sâu + tuân thủ policy cá nhân
  • Liquidity / social / distribution riêng
  • Triển khai AI như ChatGPT, Grok, Claude ngay trên Dashboard làm việc

Dự án cộng đồng cho hackathon Agent ID — không phải sản phẩm chính thức của Binance / BNB Chain, không được tài trợ hay bảo chứng bởi Binance.

    Approve / Revoke

    AI Agent only · quản lý allowance BEP-20 trên BSC trước khi swap/earn/bridge.

    ⚠️ Approve sai spender = rủi ro mất token. Mặc định Exact amount — chỉ bật Unlimited khi bạn hiểu rõ rủi ro MaxUint256.

    ⚠️ Unlimited = MaxUint256. Spender có thể rút toàn bộ allowance. Chỉ dùng với contract chính thức bạn tin tưởng.

    Bridge

    AI Agent only · tạo intent bridge (simulate → confirm). Nguồn mặc định BSC; đích có thể là chain khác.

    ⚠️ Bridge có rủi ro finality / sai địa chỉ / bridge scam. Chỉ dùng bridge uy tín (LayerZero / official).

    Cancel Limit / Stop

    AI Agent only · hủy lệnh Limit / Stop Limit đang treo (perp). Chọn từ danh sách hoặc nhập tay.

    ⚠️ Hủy nhầm lệnh có thể bỏ bảo vệ TP/SL. Simulate trước khi confirm.

    Launchpad

    AI Agent only · điền form như launchpad thật → Launch tạo prompt (simulate → confirm → deploy trên BSC).

    ⚠️ Deploy token/NFT tốn gas, rủi ro hợp đồng & thanh khoản. Quyền mint/ownable (nếu bật) thuộc hợp đồng bạn deploy — AgentGate không custodial, không tự ký. Agent phải simulate + bạn confirm trước.
